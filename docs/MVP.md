# MVP

## Golden Path

```text
Creator records canon rule
→ persistent Mind conversation stores context
→ later community submission arrives
→ Mind recalls rule and precedent
→ Loreline prepares decision
→ unresolved case gets autonomous follow-up
→ creator approves contribution
→ portable receipt records attribution
→ decision becomes future context
```

## P0 — Submission Critical

- Real Mind configured and reachable.
- Stable conversation alias per creator.
- Session A canon rule stored.
- Session B recalls rule without prompt repetition.
- Community submission reviewed against remembered canon.
- Full history visible and reproducible.
- Working web interface for the Golden Path.
- Explicit setup, timeout, malformed reply, and history failure states.
- Deployed product.
- Repository documentation.

## P1 — Winning Features

- Due-case Skill and autonomous follow-up evidence.
- Creator override updates future precedent.
- Visible context trace: loaded rule, matching precedent, prepared decision, next action.
- Test-network contribution receipt with creator approval and idempotency. Local contract and five automated tests are working; wallet flow and network deployment remain.
- Polished 1.5–2 minute demo.
- Permission test for a sender outside the Circle.

## P2 — Stretch

- Creator-platform and community connectors.
- Multiple worlds per creator.
- Rich contributor reputation.
- Revenue-split settlement.
- Advanced analytics and trend views.
- Multi-chain receipts.

## Cut Rules

P2 is removed first. Test-network settlement is reduced to a receipt if time is short. The cross-session Minds proof, community review, and visible continuity are never cut.
